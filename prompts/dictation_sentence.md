# Task: write a dictation sentence for a spelling word

Write ONE short sentence (4 to 8 words) that a parent will read aloud while a six-year-old writes
the target word.

Rules
- The sentence must contain the target word exactly once, spelled exactly as given.
- Use only words a first-grader knows. Present tense, concrete, friendly.
- The target word must be unambiguous in context (for "to/too/two" or "there/their", make the meaning clear).
- No names of real people, no scary or sad content.

Output ONLY this JSON:
{"word": "<target>", "sentence": "<sentence>"}
